# AG Refining website

Production-oriented static publishing system for AG Refining. It is designed for Vercel and can expand through the data-driven page registry in `scripts/build.mjs`.

## Local verification

```bash
npm run check
npm run build
```

The generated site is written to `dist`.

## Important content boundary

This preview deliberately avoids publishing unresolved claims about insurance, assay method, fees, exact payment timing, HIPAA compliance, licenses, material minimums, facility location, or shipping eligibility. Confirm those facts with AG Refining before strengthening public copy.

The public form prepares an email in the visitor's own email application. A production lead endpoint or approved CRM adapter should replace that behavior after the client confirms the recipient workflow.
